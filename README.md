# Digital Video Processing System

This is a hardware level computer vision file codes for filters implemented in VHDL using Xilinx Vivado. This system integrates directly with an OV7670 video camera to perform real-time Sobel edge detection, greyscale conversion, and color inversion. 
As this was an academic laboratory experiment, the system connecting code to the board and camera was preprovided, thus not present in this repo.
